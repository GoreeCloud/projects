# Contributing to GoreeCloud Projects

This is an early development-stage personal open-source project. Contributions should preserve data ownership, software quality and the mandatory GoreeCloud UI design language.

1. Open an issue describing your proposed change or bug and how to reproduce it.
2. Create a feature branch, keep changes focused and include reproducible tests.
3. For API changes update OpenAPI contracts, input validation and tests. For UI changes include accessible keyboard/mobile behavior.
4. For external packages, identify exact upstream version, license, provenance, advisories and security implications before adding them.
5. Run Python tests and browser typecheck/build. Compile native clients on a supported environment when editing them.
6. Propose a pull request; do not bypass branch protections.

Never submit secrets, production data, vendored unlicensed code or copied Plane/Linear source. No contributor license agreement or external release commitment is implied.
